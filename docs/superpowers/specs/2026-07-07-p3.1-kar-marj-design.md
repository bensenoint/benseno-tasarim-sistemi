# P3.1 — Kâr/Marj Katmanı — Tasarım Spec'i

> Tarih: 2026-07-07 · Faz: P3.1 (fırsat haritası) · EFOR: S-M · Altyapı: yeni veri yok (mevcut maliyet/satış/fatura/ödeme) · Risk: düşük

## Problem

Sistem brief bazında `maliyet, satis, fatura, odeme` topluyor ama **kâr hiçbir yerde hesaplanmıyor**. Marka detayı yalnız ham toplam gösteriyor; marj, kârlılık sıralaması, faturalanmamış/tahsil-edilmemiş iş görünürlüğü yok. Yönetici/GM "bu marka bize kazandırıyor mu?" sorusunu tek bakışta göremiyor, CSV indirip Excel'de çıkarması gerekiyor.

## Kullanıcı kararları (onaylı)

1. **Erişim:** Türetilen kâr/marj yalnız **yönetici + GM**. Ham maliyet/satış girişli herkeste kalır (SEC-4). Kâr KPI'ları yalnız yöneticide render olur.
2. **Yüzeyler:** Marka detayı · Tamamlananlar · Ody `finans_ozet` tool'u. (Genel Bakış/firma-geneli özet bu fazda DEĞİL — ileride GM kokpitine.)

## Metrik tanımları

- **Kâr** = `satis − maliyet` (ikisi de null ise kâr yok/`—`; biri null ise diğeri 0 sayılır — NOT: aşağıda netleştirildi)
  - Kesin kural: `maliyet` ve `satis` **ikisi de sayı değilse** kâr `null` (gösterme). En az biri sayıysa eksik olan 0 kabul edilir.
- **Marj%** = `satis > 0` ise `round(kâr / satis × 100)`, değilse `null`.
- **Faturalanmamış** = tamamlanmış işler içinde `fatura` false → bekleyen `Σsatis`.
- **Tahsil edilmemiş** = `fatura` true & `odeme` false → `Σsatis`.
- **Tarih-aralığı:** Tamamlananlar zaten global tarih filtresine tabi (`data.completed`); marka detayı da öyle. Kâr toplamları bu süzülmüş kümeden hesaplanır.

## Erişim kontrolü

- Yeni frontend yardımcısı: `bnsIsYonetici(currentUser, usersRec)` = `currentUser.role === 'admin' || (usersRec && usersRec.rol === 'yonetici')`. (Dashboard'da kişinin USERS kaydından `rol` okunur — mevcut `_isMgr` deseni Profile/BriefDrawer'da var; onunla hizalı.)
- Kâr/marj KPI'ları ve Tamamlananlar kâr kolonu **yalnız `bnsIsYonetici` true** iken render.
- Ody `finans_ozet` tool'u `ctx.isAdmin` VEYA DB'den `rol='yonetici'` değilse çalışmaz → "bu bilgi yöneticilere özel" döner (mevcut yildiz_karne dept/kişi kalıbı gibi).

## Bileşenler

### 1. `dashboard/app/calc.js` — saf yardımcılar (node-testable)
```js
function bnsKarMarj(b) {
  const m = (typeof b.maliyet === 'number') ? b.maliyet : null;
  const s = (typeof b.satis === 'number') ? b.satis : null;
  if (m == null && s == null) return { kar: null, marj: null };
  const kar = (s || 0) - (m || 0);
  const marj = (s && s > 0) ? Math.round((kar / s) * 100) : null;
  return { kar, marj };
}
function bnsFinansOzet(briefs) {   // tamamlanmış brief listesi
  let satis = 0, maliyet = 0, kar = 0, faturalanmamis = 0, tahsilEdilmemis = 0;
  for (const b of (briefs || [])) {
    const km = bnsKarMarj(b);
    if (km.kar != null) kar += km.kar;
    if (typeof b.satis === 'number') { satis += b.satis; }
    if (typeof b.maliyet === 'number') maliyet += b.maliyet;
    if (typeof b.satis === 'number') {
      if (!b.fatura) faturalanmamis += b.satis;
      else if (!b.odeme) tahsilEdilmemis += b.satis;
    }
  }
  const marj = satis > 0 ? Math.round((kar / satis) * 100) : null;
  return { satis, maliyet, kar, marj, faturalanmamis, tahsilEdilmemis };
}
```
`module.exports`'a ekle (node testi için).

### 2. Marka detayı (`dashboard/app/screens/Brand.jsx`)
Mevcut ham toplam bloğunun (maliyet/satış/faturalanan/tahsil) yanına, **yalnız yönetici** iken:
- **Kâr** KPI (₺, negatifse kırmızı) + **Marj%** KPI
- Mini-liste: "Faturalanmamış: ₺X (N iş)" · "Tahsil edilmemiş: ₺Y (N iş)" (o markanın tamamlananlarından)
`bnsFinansOzet(markaninTamamlananlari)` ile hesaplanır.

### 3. Tamamlananlar (`dashboard/app/screens/Completed.jsx`)
- Tabloya **Kâr** (ve/veya Marj%) kolonu — yalnız yönetici (diğer kullanıcıda kolon gizli).
- Dönem KPI şeridine **Toplam kâr** + **Marj%** kartı (yönetici-only), `bnsFinansOzet(data.completed)`'ten.

### 4. Ody `finans_ozet` tool'u (`server/ody-tools.js` + `server/queries.js`/pool)
```
description: "Kârlılık özeti (YALNIZ yönetici). kapsam: firma (genel kâr/marj/faturalanmamış) | marka (bir markanın kârı) | en_karsiz/en_karli (marka sıralaması). Maliyet/satış DB'den; kâr=satış−maliyet."
input_schema: { kapsam (enum), marka? }
run: ctx.isAdmin veya DB rol='yonetici' değilse → { hata:'bu bilgi yöneticilere özel' }. Değilse pool'dan tamamlanan brief finansını çekip bnsFinansOzet mantığıyla (server'da eşdeğer hesap) döndür.
```
NOT: server tarafında `bnsKarMarj/bnsFinansOzet` eşdeğeri gerekiyor — `calc.js` browser-global; server'da `require('../dashboard/app/calc.js')` node-export'la mümkün (formula-test.js zaten böyle require ediyor). Tek-kaynak: aynı fonksiyonu server tool'u da kullansın (ci-check tek-tanım guard'ına takılmaz — bunlar "iş metriği" değil finans; yine de calc.js'te tutmak tutarlı).
