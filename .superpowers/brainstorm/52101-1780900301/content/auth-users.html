Dashboard'a kimler giriş yapabilecek?

Bu karar veritabanı yapısını ve yönetici panelinin kapsamını belirliyor.

A

Slack'teki herkes

Sistemde kayıtlı tüm çalışanlar dashboard'a erişebilir. Şifreleri admin panelinden belirlenir. Mevcut users tablosuna username + password_hash eklenir.

B

Sadece yöneticiler / belirli kişiler

Tüm Slack kullanıcılarını değil, yalnızca seçilen kişileri dashboard'a alırsın. Ayrı bir dashboard_users tablosu. Admin panelinden yeni kullanıcı eklenir / çıkarılır.

C

Şimdilik sadece sen (tek admin)

Şimdilik tek kullanıcı, ileride genişler. En hızlı başlangıç — admin paneli gelecekte eklenir, şimdi CLI ile ilk şifre oluşturulur.
